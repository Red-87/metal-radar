# 🤘 Metal Radar

Assistente automatico per monitorare annunci di concerti metal, rock e hard rock.

## Funzioni

- Monitoraggio band
- Notifiche Telegram
- Gestione priorità
- Archivio notizie
- Analisi automatica eventi

## Priorità

- Alta: controllo ogni ora
- Media: ogni 6 ore
- Bassa: ogni 24 ore
